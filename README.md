Выполнены обе основные части: искусственные данные и кластеризация транзакций ecommerce_fraud. Дополнительные задания исключены по запросу пользователя.

Учебные материалы: analysis.ipynb с выполненными ячейками и пояснениями, analysis.py с вычислениями, исходные данные input и проверенные результаты output.

Запуск из корня:

```bash
python -m pip install -r requirements.txt
python analysis.py
```

Ноутбук можно открыть в Jupyter или Google Colab. Скрипт использует один поток вычислительных библиотек. Преобразования воспроизводимы при фиксированном random_state=8; числа и метки могут зависеть от версий библиотек, зафиксированных в requirements.txt.

Из 3024 исходных строк исключены 154 с отрицательной суммой покупки или временем на сайте. После очистки осталось 2870 покупок, включая 134 Fraud. Fraud исключён из модели, категориальные признаки применены для описания групп. Пять числовых признаков стандартизованы.

Для искусственного набора выбран k=3, силуэт 0,68698. Для транзакций максимум силуэта в диапазоне 2–10 получен при k=8 для KMeans, 0,19316, и k=3 для метода Уорда, 0,14880. Слабое разделение и низкие внешние метрики не позволяют считать полученные группы готовым детектором мошенничества.
